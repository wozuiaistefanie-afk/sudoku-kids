# 🎈 数独乐园

适合 7 岁小朋友的数独小游戏（纯网页版，双击就能玩）。

## 怎么玩

1. 用浏览器打开 `index.html`（推荐 Chrome / Safari，电脑、平板、手机都可以）。
2. 选择主题（数字 / 水果 / 动物 / 太空）、格子大小（4×4 启蒙 / 6×6 进阶 / 9×9 挑战）和难度。
3. 点一个空格，再点下面的图案填进去（用电脑玩的话，也可以按方向键选格子、按数字键填、按退格键擦除）。
4. 填对了会听到开心的音效 🎵，填重复了格子会变红并轻轻抖一下。
5. 卡住的时候可以点「💡 提示」让小狐狸帮忙。
6. 全部填对 → 彩带庆祝 🎉 + 星星奖励 ⭐。

## 说明

- 纯 HTML/CSS/JS，不需要联网、不需要安装，所有题目都是本地实时生成的，且保证只有唯一解。
- 电脑上支持键盘操作：方向键移动、数字键填数、退格键擦除。
- 进度和最佳星星会保存在浏览器里（localStorage）。
- 右上角 🔊 可以开关声音。

## 文件结构

```
数独乐园/

```
